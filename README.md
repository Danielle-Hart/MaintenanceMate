# MaintenanceMate:

## Project Description
Maintenance Mate is a Spring Boot web application designed to help apartment residents submit and track maintenance requests while allowing property managers to organize and manage them.

## Purpose
The application aims to reduce delays, miscommunication, and lost information by providing one platform for managing apartment maintenance issues.

## Target Users
- **Residents:** Submit requests and track their progress.
- **Property Managers:** Review, update, and manage maintenance requests.

## Planned Features
- Submit and track maintenance requests.
- Manage maintenance tickets and their statuses.
- Post maintenance announcements.
- Secure user login and logout.

**CRUD Operations:**
- **Create:** Submit maintenance requests.
- **Read:** View existing requests.
- **Update:** Edit requests and change statuses.
- **Delete:** Remove requests with confirmation.

## Technology Stack
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf, Bootstrap
- **Database:** MySQL, Spring Data JPA
- **Security:** Spring Security
- **Architecture:** Spring MVC
- **Tools:** IntelliJ IDEA, GitHub, phpMyAdmin, Figma/Canva

## Application Design
The interface includes a secure login page, maintenance dashboard, request submission form, request management pages, and property announcements.
